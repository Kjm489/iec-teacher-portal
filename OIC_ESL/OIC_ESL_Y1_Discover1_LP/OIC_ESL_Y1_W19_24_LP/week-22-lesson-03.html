LESSON INFORMATION & OBJECTIVES
Curriculum: OIC ESL Year 1
Theme: Working with Numbers
Week: 22
Lesson: 3
Duration: 90 minutes (2 × 45)
OIC outcomes: 1.3d, 1.3f

Measurable Learning Objectives

  1. Identify or demonstrate key ideas about numbers and number relationships using the original OIC lesson tasks.
  2. Use appropriate lesson language during a guided or paired response.
  3. Complete one independent task and explain or show the answer.

Teacher QA check: Confirm the named target words, textbook task and OIC codes against the original source. Timings refer to the seven IEC stages (8+12+15+10 / 25+10+10 = 90 minutes); original source activity descriptions may need shortening to fit. Six games are optional alternatives, not six additional required tasks.

PERIOD 1 — 45 MINUTES

1. Warm-up & Activate Prior Knowledge · 8 min

Ask children how many star jumps they can do without stopping. This may be different for each child – emphasize that this is OK. Tell children to write their number on a piece of paper. They are now going to test their predictions and see if they can jump that number of star jumps, counting out loud in English. (You can adapt this activity to suit the physical capabilities of your class.)

Diagnostic: Ask students to name, point to, or demonstrate one example before teaching.

Task ICQ: Do you listen and look first, then tell your partner one idea? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

2. Teacher Modeling — I DO · 12 min

Demonstrate the first task from the original OIC main activity using a visual or concrete example. Think aloud and model the target language: The number is ___. / I know because ___.

Check meaning: If we add one more object, does the number stay the same? Show how you know.

Task ICQ: Do you watch and listen to my example before trying it? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

3. Guided Practice — WE DO · 15 min

To warm up children’s thinking, ask them to make a list of things that can be counted at school. Encourage them to work independently first and to look around the classroom to get ideas. Set a time limit. Children compare their ideas first in pairs, and then with the class. See how many things you have together as a class. Then introduce today’s reading lesson. Ask: What parts of a text can help you to understand it better? Elicit that pictures…

Complete one example together. Elicit an answer, ask for the evidence, and correct a deliberate mistake.

CCQ: Are we counting the objects or guessing? How can we check the answer?

Task ICQ: Are we completing the first example together? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

4. Supported Pair/Group Practice · 10 min

In pairs, learners complete a fresh example using the pictures, book task or manipulatives. Partner A responds; Partner B checks and explains; then switch.

ICQs: Are you working alone or with a partner? Who checks the answer? Do you swap roles after one turn?

Support: The number is ___. / I know because ___.

Task ICQ: Does each partner have a turn to speak or show an answer? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

PERIOD 2 — 45 MINUTES

5. Independent Practice — YOU DO · 25 min

Learners complete the corresponding original OIC book/activity task individually. Select an unfamiliar example to check transfer, rather than repeating the model.

Success criteria: accurate response, appropriate numbers and number relationships vocabulary, and evidence of independent understanding.

Task ICQ: Will you complete your own answer before asking for help? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

6. Extension & Differentiation · 10 min

Create mixed-ability pairs so peer-support can be provided. Advise less confident children to underline words in the heading that also appear in the text. As an extension task for more able children, ask them to find a different text in their coursebook and to create a new heading for it.

Extension: Explain a number pattern or check a classmate’s calculation with objects.

Task ICQ: Can you use the picture or sentence starter if you need support? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.

7. Review, Formative Assessment & Exit Ticket · 10 min

Children have used headings to predict what a text is about, before reading the text in full to check their assumptions.

Exit ticket: Solve or represent a new number example and explain the answer.

Task ICQ: Do you show or say one answer without copying a partner? Lesson CCQ: Using the lesson example for “What can you count?”, which picture, action or response shows the target meaning? Explain or demonstrate.
